## Paperio Reader 2.2.0

Paperio Reader 2.2.0 adds custom book covers and a new offline Games section,
while improving weather reliability and cover-cache behavior on XTEINK X3 and
X4 readers.

### Highlights

- Added custom covers for EPUB, FB2, and FB2.ZIP books. Choose a JPG, JPEG,
  PNG, or BMP image from the book information screen, or restore the embedded
  cover later. The original book file is not modified.
- Added a Games section to the home screen and to
  `Settings → System → Tools`.
- Added Sudoku with Easy, Medium, and Hard modes, pencil notes, hints, error
  checking, a timer, saved games, and statistics.
- Added Sokoban with 155 built-in levels, level selection, undo, move and push
  counters, and saved level progress.
- Replaced the Lyra Games folder/die artwork with the four-square Apps icon in
  all Lyra layouts.

### Improvements and fixes

- Added full-size and thumbnail conversion for BMP cover images.
- Custom-cover revisions now invalidate old thumbnails and cached frames, so a
  newly selected cover appears immediately on Home, Recent Books, Book Info,
  and the finished-book screen.
- Managed custom covers follow a book when it is moved to the completed-books
  folder and are removed when the book is deleted.
- Weather now retries through a second official Open-Meteo endpoint when the
  primary request fails.
- City search distinguishes an empty result from a network failure and offers
  a retry action.
- Weather screens release the secondary framebuffer before Wi-Fi/TLS work,
  reducing network allocation failures on the ESP32-C3.
- A cached forecast remains visible when a background refresh temporarily
  fails.

### Controls

In Sokoban, use the directional buttons to move, Confirm to select a level,
Power to undo the last move, and Back to leave the game.

### Installation

Install `firmware.bin` through the SD-card firmware updater or use
`Settings → System → System Update → Check for updates` after the release has
been published.
