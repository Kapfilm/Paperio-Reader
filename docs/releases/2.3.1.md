Paperio Reader 2.3.1 для XTEINK X3, X4 и X4 Classic.

- Оптимизированы открытие и индексация FB2 и FB2.ZIP, включая переходы по главам. Исправлены отдельные случаи неверных переходов по оглавлению EPUB.
- На всех моделях обновлены поиск и повторное подключение Wi-Fi. Исправлены диалог параметров сети и перенос подсказок при вводе пароля. Подписи нижних кнопок сокращены.
- На X4 Classic подсказки «Вверх» и «Вниз» расположены у соответствующих боковых кнопок. Нижний ряд приподнят и оформлен тонкими рамками с небольшим скруглением. На X3 и X4 сохранена форма нижних кнопок из опубликованной беты.
- Для OTA используется файл, соответствующий модели ридера.

| Модель | Файл обновления |
| --- | --- |
| XTEINK X3 и X4 | `firmware.bin` |
| XTEINK X4 Classic | `firmware-x4c.bin` |

Файлы `bootloader.bin` и `partitions.bin` в релизе относятся к X3/X4. Для первой установки Paperio на X4 Classic используйте способ, рассчитанный на Classic и его таблицу разделов. Контрольные суммы файлов находятся в `SHA256SUMS`.
