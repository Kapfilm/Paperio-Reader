# Paperio Reader 2.3.4

Стабильный выпуск для **XTEINK X3, X4 и X4 Classic**. В файлах указан номер **2.3.4**, без суффиксов тестовых сборок. Для каждой модели подготовлена отдельная прошивка; обновление доступно по OTA.

## Чтение и строка состояния

- Выделение места в книге начинается с середины текущей страницы, как выбор слова для словаря. Затем границы выделения можно перемещать кнопками.
- Словарь собирает слово, перенесённое с конца строки на следующую, целиком. При этом различаются добавленный при вёрстке знак переноса и дефис исходного слова.
- В настройках строки состояния добавлено **«Заглавие раздела»**. Оно выводит родительский заголовок текущей главы — например, **«Евангелие от Луки»** вместо названия всей Библии. Положение выбирается независимо: по центру сверху, снизу или скрыть; по умолчанию элемент скрыт.
- Заглавие берётся из оглавления EPUB или вложенных разделов FB2. Если в файле нет нужной иерархии, используется доступный текущий заголовок: прошивка не пытается угадать название библейской книги по тексту.
- Убрана тильда `~` перед временем. Это изменение внешнего вида; синхронизация и хранение времени продолжают работать как прежде.
- Сохранены индивидуальная насыщенность и сглаживание текста для книги, положения элементов строки состояния и доступ к её настройкам из **Меню книги → Текст**.

## X4: обновление экрана и OPDS

В выпуск включён проверенный пользователем вариант X4 с коротким режимом быстрого обновления.

- Исправлена работа с предыдущим кадром при освобождении, заимствовании и восстановлении экранного буфера. Контроллер больше не должен получать подготовленную следующую страницу вместо показанной на экране.
- Во время фоновой индексации на X4 экранный буфер остаётся у дисплея. Фоновая работа использует свободную память и более короткие рабочие срезы, уступая чтению. Первый разбор ещё не открытой главы по-прежнему может занять время.
- В одно-буферном режиме быстрый вывод завершается до повторного использования памяти кадра; следующий переход получает актуальную базу сравнения.
- При открытии дочернего окна восстанавливается текущая страница и отменяется её отложенное сглаживание. Убрана обязательная полная очистка при каждом переходе к сноске, возврате из неё и обычном выходе из EPUB-книги. Периодическая очистка по настройке чтения сохранена.
- Одинаковые быстрые кадры пропускаются. Изменение целого процента батареи на X4 больше не запускает самостоятельную перерисовку неподвижной страницы; показание обновляется при следующем действии, изменении USB-состояния или обычном обновлении часов.
- Общая подготовка сетевых сеансов синхронизирована с отрисовкой: очистка кэша шрифтов и освобождение буфера не пересекаются с рисованием. Это относится к OPDS, Dropbox, погоде, OTA и другим разделам, использующим этот механизм.
- OPDS публикует новый список после закрытия файла кэша. Отложенный поисковый запрос потребляется до выполнения поиска, чтобы вложенная загрузка не запускала его повторно.
- Частичные полосы прогресса восстанавливают отображённый фон перед обновлением.

Диагностический журнал `paperio-x4-display.log` из тестовых сборок в релизе не записывается.

## Девять игр

В меню доступны **Судоку, Сокобан, Какуро, Виселица, Пятнашки, Йога, Delve, Электросеть и Дело №**. Названия расположены справа от иконок; под ними добавлены короткие описания уменьшенным шрифтом. Иконки сохраняют общий контурный стиль и сплошной фон при выделении.

### Йога — Peg Solitaire

Два поля: классический крест и треугольник. Перепрыгивайте одной фишкой через другую в свободную лунку и старайтесь оставить одну фишку. Есть отмена ходов, подтверждение перезапуска, правила и отдельное сохранение каждого поля.

### Delve

Пошаговое исследование десяти этажей подземелья на русском языке: комнаты, враги, факел, снаряжение, зелья, свитки и рюкзак. Доступны обычный и увеличенный масштабы поля; камера следует за героем. В крупном масштабе сохранён рисунок стен с более толстыми полосками, увеличены сообщения, уточнены размеры и отступы верхних показателей.

Кнопка «Выбор» открывает рюкзак. В меню есть продолжение, рюкзак, спуск, осмотр врагов, ожидание хода, отдых, настройки и правила. Рядом с числом здоровья показана небольшая шкала.

### Электросеть — Lamplighter

**600 задач**: по 200 на полях 5×5, 7×7 и 9×9. Поворачивайте провода, чтобы соединить источник со всеми лампами. На поле нет сетки вокруг каждой клетки: ориентиры отмечены точками, квадрат выделяет выбранную клетку. Активные провода толще неактивных, подключённые лампы закрашены. Есть закрепление, отмена, подсказка, выбор сложности и переход между задачами.

### Дело № — Case Files

**600 дел**, три сложности и шесть сюжетов. Нужно сопоставлять персонажей, места, предметы и время по уликам.

- Название содержит номер дела; история и цель находятся под ним в общей рамке.
- Улики, вертикальные карточки таблиц и игровое поле разделены на одном экране. Переключение карточки сразу меняет таблицу поля.
- Долгое нажатие «Выбор» переключает активную область. В области улик долгое нажатие «Вправо» открывает полный список улик по порядку.
- Полные подписи выбранной строки и столбца расположены под полем. Подсказка сообщает: **«Подсказка изменила отметку.»**
- При успешном прохождении появляется окно с выбором следующего дела или возврата в меню.

### Какуро: полностью новый набор и геймплей

Прежняя версия из независимых блоков 3×3 заменена на **600 задач**: по 200 на полях **6×6, 7×7 и 8×8**. Сохранена наша иконка.

- Цепочки пересекаются и имеют разную длину. В каждой цепочке цифры 1–9 должны дать указанную сумму без повторов.
- Под полем показаны суммы и допустимые сочетания цифр для выбранной клетки. Подсказки идут компактным блоком над палитрой; полный список сочетаний открывается отдельно.
- Поле центрируется в свободной области между заголовком и подсказками для всех размеров задач.
- Проверяются повторы и неверные суммы; подсказанные цифры подчёркнуты и защищены от изменения. Есть отмена хода, перезапуск, следующий и предыдущий номер, выбор сложности и сохранение прогресса.

**Старое сохранение Какуро не переносится в новый набор:** номера и поля теперь другие. Прежний файл остаётся на SD-карте; новая версия хранит прогресс отдельно.

Новые игры адаптированы из проекта [Touch Licorice apps](https://github.com/omer-faruq-xteink/touch-licorice-apps) Омера Фарука Инеля, MIT. Авторство и лицензии сохранены в исходниках.

## Небольшой экран X3

Для экрана **528×792** программно проверено размещение всех девяти игр, включая три размера интерфейса и реальные метрики шрифтов.

- Длинные слова «Виселицы» сохраняют все буквы: сначала убираются необязательные пробелы, затем при необходимости уменьшается шрифт. Отметка использованной подсказки не перекрывает пояснение.
- В Судоку заголовок ограничен местом перед таймером; цифры заметок уменьшены до размера маленьких ячеек.
- В «Йоге» место для результата и рекорда учитывает выбранный размер шрифта и не пересекает нижние кнопки.
- Поля, карточки, подписи и всплывающие окна «Дело №» проверены на размерах X3 и X4. Длинные улики доступны полностью.

Эти проверки подтверждают геометрию и работу с текстом; визуальная проверка всех экранов на физическом X3 не проводилась.

## Мини и другие элементы интерфейса

В теме **Мини** возвращены прямые углы обложки. Уменьшенные проценты и счётчики страниц под ней сохранены при всех трёх размерах интерфейса. В интерфейсные шрифты добавлен знак **№**, поэтому номера дел отображаются без пропуска символа.

## Экран сна X4 Classic

Только на **X4 Classic** добавлена заставка **«Словесные часы»** на русском языке. Время выделяется словами в сетке букв с шагом пять минут, а четыре точки показывают дополнительные минуты. Неактивные буквы меньше и используют обычное начертание; слова текущего времени выделены белым на чёрном фоне.

Сохранены перекидные часы со специальным шрифтом и вариант **«Календарь + погода + часы»**. Часы обновляются по минутам с периодической очисткой экрана. **Быстрый сон оставляет текущую страницу**, даже если для глубокого сна выбрана заставка с часами.

**На X3 и X4 работающих часов на заставке нет.** Календарь, календарь с погодой и часы строки состояния остаются доступны.

## Установка и OTA

| Модель | Файл релиза |
| --- | --- |
| XTEINK X3 | `firmware-x3.bin` |
| XTEINK X4 | `firmware-x4.bin` |
| XTEINK X4 Classic | `firmware-x4-classic.bin` |

- На установленной Paperio откройте **Настройки → Система → Обновление системы → Проверить обновления**. Для стабильного выпуска 2.3.4 включать бета-обновления не требуется; файл выбирается по модели.
- Для ручного обновления с SD используйте файл своей модели. На залоченном X3 или X4 с уже установленной Paperio используйте привычный способ установки через загрузчик или обновление с SD; разблокировка USB ради этого выпуска не нужна.
- Для совместимости со старыми OTA сохранены `firmware.bin` — общая сборка X3/X4 с определением модели при запуске — и `firmware-x4c.bin`, псевдоним образа X4 Classic.
- Если загрузка OTA старой версии останавливается на 0%, один раз установите актуальный файл своей модели с SD-карты.
- Контрольные суммы опубликованы в `SHA256SUMS`, сведения об образах — в `firmware-manifest.json`.

## Проверка выпуска

Пользователь проверил последний вариант X4 с коротким обновлением экрана и подтвердил нормальную работу. Изменения X4 Classic проверялись поэтапно на подключённом ридере. Для X3 выполнены программные проверки полей, текстов и размеров интерфейса.

Нативные проверки охватывают игровые модели, все 600 задач Какуро, сочетания цифр, сохранения и повреждённые данные, словесные часы для всех 1440 минут суток, иерархию оглавления, управление экранными буферами и команды контроллера. Релизные образы проверяются на соответствие модели, структуру и контрольную сумму. Сравнительная оценка автономности в часах не проводилась.
