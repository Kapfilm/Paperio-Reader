Paperio Reader 2.1.4 добавляет переключение между Paperio и inkMOD, установленными в двух слотах, без перепрошивки.

- «Настройки → Обновление системы → Переключить прошивку»: проверка образа, отображение названия и версии, подтверждение переключения.
- Проверяются платформа ESP32-C3, границы сегментов, контрольная сумма и SHA-256 при её наличии. Пустой или повреждённый слот выбрать нельзя.
- Подтверждение успешной загрузки и аварийное восстановление для обычных обновлений Paperio сохранены.

### Установка и переключение

1. Установите Paperio 2.1.4 `firmware.bin` через обновление с SD-карты и оставьте рабочий экран открытым хотя бы на минуту.
2. Из Paperio через обновление с SD-карты установите совместимый образ приложения inkMOD с переключателем слотов. inkMOD займёт другой слот, а Paperio останется в текущем. Полный образ флеш-памяти с загрузчиком для этого не подходит.
3. В inkMOD выберите другой слот для возврата в Paperio. В Paperio используйте «Переключить прошивку» для возврата в inkMOD.

**Важно: OTA и обновление с SD-карты перезаписывают другой слот. Обновление из Paperio удалит установленную там inkMOD. Само переключение ничего не стирает.** После обновления Paperio inkMOD можно установить снова по шагу 2.

[Подробная инструкция в README](https://github.com/Kapfilm/Paperio-Reader/blob/2.1.4/README.md).

Пользователь подтвердил переключение на ридере в тестовой сборке 2.1.3-dualboot-test1. В релизной сборке изменён номер версии при сохранении кода переключения. Отдельно выполнены проверка финального релизного BIN и 50 целевых автоматических тестов; новый BIN ещё не проверялся на устройстве.

Спасибо разработчику [alpzoloto-sudo/inkmod](https://github.com/alpzoloto-sudo/inkmod) за исходный код FB2 и реализацию переключения слотов, использованные при разработке Paperio.

Для обычного обновления требуется только `firmware.bin` или идентичный BIN с названием версии. ELF/MAP предназначены для диагностики. Для передачи книг приложены утилита `serial_transfer.py` и плагин `microreader-paperio.zip`; инструкция находится в README.
