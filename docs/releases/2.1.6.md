Paperio Reader 2.1.6 добавляет числовой выбор размера шрифта в общие настройки и настройки отдельных книг.

- В «Настройки текста → Размер» включите «Числовые размеры». Станут доступны все установленные размеры выбранного семейства шрифтов с SD-карты.
- Меню EPUB/FB2 → «Настройки книги» → «Размер шрифта книги» показывает такой же числовой список. Размер применяется сразу и сохраняется для книги. «По умолчанию» возвращает общую настройку.
- Исправлена подпись строки: она управляет текстом книги, а не интерфейсом.
- Исправлено сохранение отображаемой страницы и позиции при автоматическом сне с быстрым возобновлением.

Пользователь проверил числовые размеры шрифта на ридере в тестовой сборке 2.1.5-font-size-fix3. В релизе сохранён этот код; изменены только версия и документация. Этот релизный BIN ещё не проверялся отдельно на устройстве.

### Установка

Для обычного обновления скачайте `firmware.bin` или идентичный `firmware-Paperio-Reader-2.1.6.bin` и установите через обновление с SD-карты. ELF/MAP предназначены для диагностики. Загрузчик и таблица разделов для обычного обновления не нужны.

**OTA и обновление с SD-карты перезаписывают неактивный слот. Если там установлена inkMOD, она будет заменена. Переключение между уже установленными образами прошивки ничего не стирает.**

[Инструкции по установке, переключению прошивки и передаче книг по USB](https://github.com/Kapfilm/Paperio-Reader/blob/2.1.6/README.md). Для передачи книг сохранены вложения `serial_transfer.py` и `microreader-paperio.zip`.

Спасибо разработчику [alpzoloto-sudo/inkmod](https://github.com/alpzoloto-sudo/inkmod) за исходный код поддержки FB2 и переключения слотов.

Прошивка прошла 74 автоматических теста, включая проверку финального BIN. Контрольные суммы приложены в `SHA256SUMS.txt`.
