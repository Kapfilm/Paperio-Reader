## Paperio Reader 2.2.1

Paperio Reader 2.2.1 expands the offline Games section with three new games,
adds new play modes, and improves several screens and controls on XTEINK X3
and X4 readers.

### New games

- Added Kakuro with Easy, Medium, and Hard puzzles, hints, error checking, a
  timer, automatic saving, and statistics.
- Added Hangman with English and Russian word sets, categories, hints, saved
  games, and win/loss statistics.
- Added a harder Hangman difficulty with less common words, fewer allowed
  mistakes, and no reveal-letter hint.
- Added a two-player Hangman mode: one player enters a custom word, hands the
  reader over, and the second player guesses it.
- Added 15 Puzzle with solvable shuffling, a move counter, automatic saving,
  and a choice of controls that follow either the empty cell or the moving
  tile.

### Improvements and fixes

- Fixed the bottom controls in the Kakuro game menu.
- Improved the Sokoban level-complete screen with a bold heading, compact
  divider, clear move and push counters, and a matching Next button label.
- Added icons and the firmware version to the Mini theme menu and header.
- Added a visual separator before button backup and restore in control
  settings.
- Improved book information layout so long titles, authors, and reading data
  remain visible instead of extending beyond the right edge.
- Increased periodic full refresh frequency while reading on X3 to reduce
  visible traces from previous pages.

### Compatibility

- Existing Sudoku, Sokoban, and Hangman saves remain supported.
- This is a single firmware image for both XTEINK X3 and X4.

### Installation

Install `firmware.bin` through the SD-card firmware updater, or use
`Settings → System → System Update → Check for updates` after the release has
been published.
