# Paperio Reader 1.2.0

Обновление на основе протестированной сборки 1.1.0-reading-fixes.3.

## Главное

- Исправлены неправильные переходы по EPUB-ссылкам, включая совпадающие имена файлов в разных папках и кодированные якоря.
- Исходная позиция сохраняется перед переходом в примечание. Добавлена история до восьми вложенных переходов; синхронизация KOReader использует позицию в книге.
- Окно примечаний: полный текст, вложенные ссылки, предыдущая/следующая сноска исходной страницы и возврат в книгу.
- В оглавлении боковые кнопки перемещают выделение на пять глав, передние — на одну.
- Три шрифта интерфейса: «По умолчанию», «Тёмный», Golos Text. Настройка сохраняется после перезапуска.
- Профили размера шрифта и межстрочного интервала для отдельной книги.

## Установка

По Wi-Fi: **Настройки → Система → Обновление прошивки**.

Для ручного обновления скачайте `firmware.bin` или `firmware-Paperio-Reader-1.2.0.bin`: файлы идентичны. Это образ приложения, не объединённый образ для прошивки с адреса 0.

Шрифт интерфейса: **Настройки → Экран → Шрифт интерфейса**. Golos Text использует Medium для обычных надписей и SemiBold для выделенных заголовков. Вывод остаётся чёрно-белым, без полутонового сглаживания.

Проверка новых функций выполнена пользователем на тестовой сборке. Релизная сборка имеет номер 1.2.0; отдельное обновление по OTA на физическом устройстве проверяется после публикации. Изменения экрана сна в этот релиз не вносились.
