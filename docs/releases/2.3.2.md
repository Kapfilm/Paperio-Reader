Paperio Reader 2.3.2 для XTEINK X3, X4 и X4 Classic. Все образы показывают версию 2.3.2 на устройстве.

| Модель | Файл для ручной установки |
| --- | --- |
| XTEINK X3 | `firmware-x3.bin` |
| XTEINK X4 | `firmware-x4.bin` |
| XTEINK X4 Classic | `firmware-x4-classic.bin` |

- На X4 исправлено двоение при навигации в меню с быстрым обновлением экрана.
- При смене главы FB2 и FB2.ZIP окно «Индексация» скрыто.
- Сборка для X4 Classic включает USB-накопитель, исправленную шкалу прогресса и ускоренную работу с иллюстрациями.

Для OTA откройте «Настройки → Система → Обновление системы → Проверить обновления». Версия 2.3.2 выбирает файл по модели ридера. Более ранние версии используют совместимые имена `firmware.bin` для X3 и X4 и `firmware-x4c.bin` для X4 Classic. В этом релизе X3 и X4 используют одну сборку, которая определяет модель при запуске.

Контрольные суммы находятся в `SHA256SUMS`.
