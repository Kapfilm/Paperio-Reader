Тестовая версия для XTEINK X3 и X4 на основе 2.2.6-rc.5.

- Исправлена отрисовка пользовательского шрифта с SD после фоновой подготовки главы. Если в памяти находятся только размеры символов, изображение нужного символа загружается отдельно; смещение в файле больше не используется как адрес изображения в памяти. Это соответствует месту сбоя X3 из отчёта rc.5.
- Закрытие файлов SD при уничтожении и замене файлового объекта защищено теми же блокировками, что и явное закрытие. Это устраняет обход синхронизации SD-карты с экраном на общей SPI-шине, способный привести к конфликтам транзакций.
- При задержке захвата SPI-блокировки операции ждут её освобождения вместо обращения к занятой шине.
- Исправлено чтение невыровненных таблиц пользовательских шрифтов из flash-кэша: данные загружаются в выровненную область памяти.
- Блокировка хранилища поддерживает вложенные операции чтения и записи — например, при потоковом сборе примечаний или повторном открытии файла.
- Исправлена проверка диапазона памяти при сохранении стека аварии: обычный выровненный указатель стека больше не приводит к пустому разделу отчёта.
- В README добавлены изменения rc.6. Полные встроенные примечания обычного размера из rc.5 сохранены.

Отчёт X4 содержит ошибку владения блокировкой без стека вызовов; устранение перезагрузок после этих исправлений нужно проверить на устройстве с пользовательским шрифтом.

Для OTA включите бета-обновления. Стабильный канал остаётся на 2.2.5. Для установки с SD используйте **firmware.bin**.
