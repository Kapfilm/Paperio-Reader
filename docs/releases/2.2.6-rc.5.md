Тестовая версия для XTEINK X3 и X4 на основе 2.2.6-rc.4.

- Встроенным примечаниям EPUB, FB2 и FB2.ZIP возвращён обычный размер шрифта абзаца; курсив сохранён.
- Убрано обрезание текста примечания при сборе до 240 байт и последующее сокращение до нескольких строк. Полный текст обрабатывается частями с SD, без большого буфера в памяти; длинное примечание может продолжаться на следующей странице.
- Исходный номер ссылки остаётся на месте. Повторный маркер в начале самого примечания удаляется при уверенном совпадении, без удаления содержательных чисел.
- Кэш примечаний и страницы с включёнными примечаниями автоматически перестраиваются; прогресс, закладки и выделения сохраняются.
- Ответы Dropbox собираются небольшими проверяемыми блоками памяти; сетевое соединение закрывается до разбора ответа. Убран рост большого непрерывного буфера при работающем TLS; отказ выделения блока возвращает ошибку, данные аккаунта сохраняются. Отчёт rc.4 подтверждает аварийное завершение C++, но без полного стека конкретное место ошибки неизвестно; поведение X3 после исправлений нужно проверить на устройстве.
- README дополнен важными изменениями всей тестовой ветки: компактные заголовки, Dropbox, список папок и книг, примечания и восстановление кэша. В артефакт сборки GitHub добавлен точный ELF для разбора будущих отчётов о сбоях.

Для OTA включите бета-обновления. Стабильный канал остаётся на 2.2.5. Для установки с SD используйте **firmware.bin**.
