## Paperio Reader 2.2.2

Paperio Reader 2.2.2 improves battery and charging behavior, long-running
automatic page turning, FB2 typography and archive reliability, and the Mini
theme on XTEINK X3 and X4 readers.

### Battery and charging

- Improved X4 battery estimation while charging, after unplugging, and when
  entering or leaving quick sleep. The upper range now follows the charger
  taper more closely, so 100% better matches the green charge indicator and no
  longer drops immediately to the high-eighties after unplugging.
- Battery percentage can now refresh while the reader is idle on the charger;
  pressing a button is no longer required to see charging progress.
- Corrected the default BQ27220 capacity configuration on X3 and made gauge
  initialization incremental and safer.
- Fixed the X3 charging icon remaining active after the cable was disconnected.
- Added spacing between battery percentage and time in the reading status bar.

### Reading and FB2

- Fixed a long-session automatic page-turn issue that could eventually leave
  the reader unresponsive.
- Added more complete FB2 semantic formatting for chapter titles, subtitles,
  epigraphs, citations, annotations, author lines, dates, links, images, and
  inline code.
- Reduced FB2 heading sizes for a more balanced page layout on the compact
  X3/X4 displays.
- Hardened FB2.ZIP extraction for fragmented memory by reducing mandatory
  staging memory, allocating optional DEFLATE tables only when needed, and
  lowering inflater stack usage.
- Preserved reading position and bookmarks when upgrading recent FB2 cache
  formats; books are reindexed only when the new typography requires it.

### Interface and localization

- Added a compact bold `EPUB` or `FB2` format badge to book covers in the Mini
  theme. The detected format is retained for books stored in generic ZIP
  archives.
- Bundled only English and Russian translations to reduce firmware size.
  Devices configured to a removed language migrate safely to English.

### Compatibility

- A one-time FB2 reindex may occur after installation because the generated
  book styles changed. Reading positions and bookmarks remain preserved.
- Existing settings remain supported. If a previously selected language is no
  longer bundled, English is selected automatically.
- This is a single firmware image for both XTEINK X3 and X4.

### Installation

Install `firmware.bin` through the SD-card firmware updater, or use
`Settings → System → System Update → Check for updates` after the release has
been published.
