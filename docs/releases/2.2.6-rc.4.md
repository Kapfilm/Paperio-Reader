Тестовая версия для XTEINK X3 и X4 на основе 2.2.6-rc.3.

- Исправлена ориентация значка Dropbox в «Меню»: чёткий контур и прозрачный фон в обычном и выбранном состоянии.
- Вместо подписи «[Папка]» в Dropbox показан значок папки. Все строки имеют одинаковую компактную высоту, без дополнительного интервала между папками и книгами.
- Форматы epub, fb2 и fb2.zip размещены отдельной колонкой справа. Длинное название сокращается, формат остаётся видимым.
- Из списка убраны «Обновить список с начала» и «Настройка Dropbox». Первое подключение доступно через «Настройки → Система → Dropbox», изменение настроек — через веб-интерфейс («Меню → Передача файлов → Dropbox»). Переход в следующую страницу сохранён.
- Снижена пиковая нагрузка на память при чтении папок: JSON запроса освобождается до TLS, строки ответа не дублируются при разборе, массив списка выделяется заранее. Отключена периодическая перерисовка во время сетевого сеанса. Устранение неожиданной перезагрузки X3 требует проверки на устройстве.
- Встроенные примечания в EPUB, FB2 и FB2.ZIP уменьшены до 85% размера текста абзаца; курсив сохранён. Размер и стиль основного текста после примечания восстанавливаются. Страницы с включённым предпросмотром перестроятся автоматически, прогресс сохранится.

Для OTA включите бета-обновления. Стабильный канал остаётся на 2.2.5. Для установки с SD используйте **firmware.bin**.
