# Paperio Reader 2.1.2

Исправлен непреднамеренный откат к предыдущей прошивке при выборе USB: старый пункт напрямую загружал второй OTA-раздел, в котором после обновления могла находиться резервная версия Paperio. Такое переключение удалено.

Пункт **«Передача по USB»** теперь открывает встроенный режим передачи файлов в текущей прошивке. USB Serial не создаёт обычный диск в Finder или Проводнике: требуется утилита или плагин Calibre. Механизм аварийного восстановления сохранён.

## Программы для компьютера

- **serial_transfer.py** — управление файлами на SD-карте, включая FB2, FB2.ZIP и EPUB. Требуются Python 3 и pyserial.
- **microreader-paperio.zip** — отдельная версия плагина MicroReader для Calibre, адаптированная к путям Paperio и ожиданию готовности ридера после подключения. Предназначена для EPUB; установите ZIP через «Настройки → Плагины → Загрузить плагин из файла». Установка прошивки MicroReader не требуется.

[Подробные инструкции в README](https://github.com/Kapfilm/Paperio-Reader/blob/2.1.2/README.md): установка на macOS, команды загрузки и скачивания, интерактивный режим, выбор порта и устранение неполадок. Там же приведены ссылки на файлы и оригинальный плагин.

Спасибо [CidVonHighwind / MicroReader](https://github.com/CidVonHighwind/microreader) за протокол и плагин. Адаптация для Calibre распространяется отдельно с исходным кодом и сохранённой лицензией GPL-2.0; она не является компонентом прошивки. Благодарность разработчику [inkMOD](https://github.com/alpzoloto-sudo/inkmod) за основу поддержки FB2 сохранена в README.

## Установка прошивки

Используйте **firmware.bin** или идентичный **firmware-Paperio-Reader-2.1.2.bin** для обычного обновления. Плагин и утилита Python предназначены для компьютера; их нельзя выбирать в качестве прошивки.

Проверены сборка ESP32-C3, 39 тестов USB Serial/BootHealth/OTA, целостность BIN и отсутствие старого USB-переключателя в исполняемом файле. Тесты плагина проверяют программную логику с имитацией подключения; взаимодействие Calibre с физическим ридером ещё требует проверки на устройстве.

**Полный список изменений**: https://github.com/Kapfilm/Paperio-Reader/compare/2.1.1...2.1.2
