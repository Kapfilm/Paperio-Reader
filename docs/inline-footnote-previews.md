# Встроенный предпросмотр примечаний

Настройка **Настройки → Чтение → Встроенный предпросмотр примечаний** добавляет текст
примечания сразу после ссылки на него в основном тексте книги. С версии **2.2.6** используется
обычный размер шрифта абзаца, курсив сохранён. Убраны прежние ограничения в 240 байт и несколько
строк; длинные примечания читаются с SD-карты частями и могут продолжаться на следующих страницах.
Исходная ссылка на сноску сохраняется. Повторный номер в начале примечания удаляется только при
уверенном совпадении с маркером ссылки; содержательные числа текста сохраняются.

Полный текст также доступен обычным переходом по ссылке. Отдельного блока сносок в подвале
страницы эта настройка не создаёт.

У отдельной книги есть такое же переопределение: **Переопределения для книги → Встроенный
предпросмотр примечаний**. Значение «По умолчанию» использует общую настройку; «Вкл» или «Выкл»
задают выбор только для этой книги и имеют приоритет над общей настройкой.

## Исправление в 2.2.6

- Для FB2 и FB2.ZIP сборщик теперь читает главы через тот же потоковый интерфейс, что и сам ридер.
  Раньше он всегда пытался читать ZIP, хотя служебные главы FB2 создаются иначе. Результатом мог
  стать пустой кэш, который считался успешным и больше не пересобирался.
- Для EPUB поддержаны старые якоря вида `<a name="note1">`, наряду с `id`. Переход к таким
  примечаниям уже работал, но сборщик предпросмотра не находил текст назначения.
- Ошибка чтения или отмена сбора не сохраняется как успешный пустой результат.
  Страницы, временно построенные без предпросмотра, не подменяют кэш страниц с примечаниями;
  после успешного сбора примечания снова добавляются при построении страниц.
- Кэш предпросмотров и страницы с включённым предпросмотром автоматически перестраиваются.
  Книги, закладки, выделения и записи прогресса не удаляются; сброс настроек не требуется.

После обновления включите настройку и заново откройте книгу. При первом сборе может появиться
сообщение о сборе примечаний. Если общий переключатель включён, а у конкретной книги задано
«Выкл», выберите для неё «По умолчанию» или «Вкл».

Предпросмотр предназначен для распознаваемых ссылок на примечания: семантических ссылок EPUB
и коротких цифровых или символьных маркеров. Обычные ссылки на другие главы не разворачиваются
намеренно.
