# Загрузка книг из Dropbox

Dropbox доступен на XTEINK X3 и X4 в меню **Настройки → Система → Dropbox** (группа «Сеть»).
Прошивка показывает книги и вложенные папки, начиная с выбранной стартовой папки,
и скачивает выбранный файл на SD-карту. Быстрый пункт **Dropbox** расположен в домашнем
разделе **Меню** перед OPDS, а также доступен в системных настройках.
Книги в облаке не изменяются. Прогресс чтения, цитаты и закладки через Dropbox не передаются.

## 1. Создайте приложение Dropbox

1. Войдите в свой аккаунт и откройте [создание приложения](https://www.dropbox.com/developers/apps/create).
2. Выберите **Scoped access**, затем **App folder**.
3. Задайте уникальное имя, например `PaperioReader-Kapfilm`, и нажмите **Create app**.
4. На вкладке **Permissions** включите `files.metadata.read` и `files.content.read`, затем нажмите **Submit**.
5. На вкладке **Settings** скопируйте **App key**. **App secret** и кнопка генерации временного access token не нужны.

В режиме App folder прошивке доступна только папка этого приложения. После первого подключения
она появится в Dropbox в разделе **Apps / Приложения** с именем, указанным в **App folder name**.
Для собственного аккаунта достаточно режима разработки приложения.

[Официальное описание App Console](https://docs.dropboxapi.com/dropbox-api/docs/get-started/tutorial/app-console)
и [авторизации OAuth](https://docs.dropboxapi.com/dropbox-api/docs/oauth).

## 2. Подключите аккаунт на ридере

1. При первом подключении откройте **Настройки → Система → Dropbox → Настройка**.
   Для изменения уже подключённого аккаунта откройте **Меню → Передача файлов** и веб-интерфейс ридера;
   в нём доступен раздел Dropbox. В списке книг отдельной строки настройки больше нет.
2. В режиме веб-сервера выберите **Подключиться к сети** и подключите ридер к Wi-Fi с интернетом.
   Режим собственной точки доступа ридера не предоставляет ему интернет.
3. На телефоне или компьютере в той же сети откройте адрес, показанный на экране ридера,
   и выберите **Dropbox**. Можно добавить `/dropbox` к адресу вручную.
4. Вставьте **App key**. Оставьте «Папка в Dropbox» пустой, чтобы использовать корень папки приложения.
   Для вложенной папки укажите путь относительно неё, например `/Books`.
   Путь `/Apps/имя-приложения` вводить не нужно.
5. Укажите папку на SD-карте, по умолчанию `/Dropbox`, и сохраните настройки.
6. Нажмите кнопку получения ссылки и откройте её в новой вкладке браузера.
7. Войдите на сайте Dropbox и разрешите чтение папки. Скопируйте показанный Dropbox одноразовый код
   обратно на страницу ридера и завершите подключение.
8. Закройте режим веб-сервера на ридере. Штатный перезапуск восстановит память для обычного чтения.

Ссылка подключения действует 10 минут и привязана к текущему сеансу ридера.
Если ридер перезапустился или ссылка устарела, получите новую ссылку и код.
Пароль Dropbox вводится только на сайте Dropbox. Долгосрочное разрешение хранится в NVS ридера
и не попадает в файлы экспорта настроек или на SD-карту. Смена App key требует нового подключения;
смена папки с книгами — нет.

## 3. Скачайте книгу

Положите EPUB, FB2, FB2.ZIP, TXT, XTC/XTC-H или Markdown в выбранную папку Dropbox.
Откройте **Настройки → Система → Dropbox**, выберите книгу и подтвердите скачивание.
Если книг много, используйте пункт следующей страницы.
Папки можно создавать обычным способом в Dropbox с компьютера или телефона. На ридере
выберите строку со значком папки, чтобы войти в неё. Кнопка **Назад** возвращает в родительскую
папку, а из стартовой папки выходит из Dropbox. Выше выбранной стартовой папки перехода нет.
Следующая страница относится к текущей папке. Для повторного чтения списка вернитесь в родительскую
папку и откройте нужную снова; для стартовой папки выйдите из Dropbox и зайдите заново.
Файлы из всех папок скачиваются в одну выбранную папку на SD-карте; дерево каталогов
автоматически не копируется, папки в облаке ридер не создаёт.

Во время передачи показывается прогресс. Кнопка **Назад** отменяет загрузку при обработке очередного
поступившего блока данных. Готовая книга появляется в выбранной папке SD и открывается обычным
обозревателем файлов прошивки. После скачивания интернет для чтения не нужен.

Существующий файл с таким же именем не перезаписывается. При необходимости переименуйте его
или выберите другую папку загрузки. Символы, недопустимые в именах FAT, заменяются подчёркиваниями.
Файлы загружаются во временный `.part` и получают окончательное имя после успешного завершения;
при штатной отмене или ошибке временный файл удаляется.

## Если подключение или загрузка не удались

- Проверьте интернет именно на ридере и правильность разрешений приложения.
- Для папки приложения используйте пустой путь или `/Books`, а не полный путь `/Apps/...`.
- При истёкшем коде получите новую ссылку. При отозванном доступе подключите аккаунт заново.
- Если Dropbox временно ограничил число запросов, повторите попытку позже.
- Проверьте свободное место и наличие SD-карты; защищённая служебная папка `.crosspoint` не подходит для загрузок.
- Кнопка отключения аккаунта находится на странице `/dropbox`. При необходимости доступ также можно
  отозвать в настройках подключённых приложений на сайте Dropbox.
