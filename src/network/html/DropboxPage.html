Dropbox

Загрузка книг из одной папки на SD-карту. После скачивания книги доступны без интернета.

Проверяем подключение…

Для подключения Dropbox ридер должен быть подключён к домашней сети Wi-Fi с интернетом. Режим точки доступа ридера сам по себе не даёт доступ к Dropbox.

1. Настройте папку

Публичный ключ приложения, не App secret и не пароль аккаунта.

Путь внутри папки приложения: например, /Книги. Для её корня оставьте поле пустым. Просматривается только эта папка, без вложенных папок.

Где взять App key
  1. Откройте Dropbox App Console в браузере телефона или компьютера и создайте приложение.
  2. Выберите Scoped access и доступ App folder. Назовите приложение, например, PaperioReader; Dropbox может попросить выбрать другое свободное имя.
  3. На вкладке Permissions включите files.metadata.read и files.content.read, затем сохраните кнопкой Submit. Разрешения записи не нужны.
  4. На вкладке Settings скопируйте App key в поле выше. Для приложения должна быть разрешена авторизация публичного клиента с PKCE. Redirect URI оставьте пустым — Dropbox покажет код для копирования.
  5. Книги положите в папку Приложения / имя вашего приложения в Dropbox (в английском интерфейсе — Apps). Эта папка появляется после подключения аккаунта. Не вписывайте её полный путь в поле папки выше.

2. Подключите аккаунт

Откройте Dropbox в новой вкладке, разрешите чтение папки приложения, затем скопируйте показанный Dropbox код сюда. Пароль вводится только на сайте Dropbox.

Открыть Dropbox в новой вкладке

Если код устарел или ридер перезапустился, получите новую ссылку. Менять папку с книгами можно без повторного входа. При смене App key аккаунт потребуется подключить заново.

3. Скачивайте книги на ридере

Закройте режим веб-сервера на устройстве. Откройте Настройки → Система → Dropbox, выберите книгу и подтвердите скачивание. Существующие файлы не перезаписываются.

Поддерживаются EPUB, FB2, FB2.ZIP, TXT, XTC/XTC-H и Markdown. Содержимое Dropbox не изменяется.
